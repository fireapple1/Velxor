Worker A(백엔드 개발자)가 자신이 전송하는 데이터가 프론트엔드에서 어떻게 시각화되는지 정확히 이해하고, 백엔드 로직(이벤트 발생 주기, 페이로드 데이터 등)을 UI에 맞춰 최적화할 수 있도록 작성된 3가지 UI 테마별 구현 명세서(프롬프트)입니다.

A에게 바로 복사해서 전달하실 수 있도록 작성했습니다.

### 1. Dark Cyberpunk (다크 사이버펑크) 테마 연동 명세서

**[프론트엔드 렌더링 컨셉]**

* **시각적 목표**: 완전한 암전(Deep Black) 상태에서 랜섬웨어 탐지 시 강렬한 **네온 레드(Neon Red)가 점멸**하는 시각적 충격 극대화.
* **주요 색상**: 바탕(#0a0a0c) / 정상 노드(#00ffcc, 청록) / 위협 노드(#ff3333, 핏빛 빨강)

**[백엔드(A) 데이터 연동 요구사항]**

1. **`node_add` 이벤트 (정상 상태)**:
* A가 이벤트를 쏘면 UI에는 차가운 청록색 테두리의 노드가 조용히 생성됩니다.


2. **`verdict: "ransomware"` 수신 (위협 상태)**:
* **Latency가 핵심입니다.** A의 분석 엔진 판정이 WS를 통해 도착하는 즉시, 해당 프로세스 노드와 연결선(Edge)에 0.8초 주기의 붉은색 펄스(Pulse) 애니메이션이 발동됩니다. (데모의 하이라이트)


3. **`POST /block` 차단 응답 (`killed`)**:
* A의 차단 로직이 성공하여 `killed`가 떨어지면, 붉게 뛰던 노드가 즉각 차가운 쥐색(#444)으로 죽어버립니다(Dead State). 상태 전환이 극적이므로 차단 API의 응답 속도가 빠를수록 효과가 좋습니다.

### 2. Futuristic Holographic (미래지향적 홀로그램) 테마 연동 명세서

**[프론트엔드 렌더링 컨셉]**

* **시각적 목표**: SF 영화(JARVIS)의 투명 홀로그램 관제 시스템. 글래스모피즘(반투명)과 스캔 애니메이션을 활용한 하이테크 느낌 부여.
* **주요 색상**: 반투명 딥 블루(배경) / 야광 시안(테두리 빛) / 마젠타 핑크(위협 경고)

**[백엔드(A) 데이터 연동 요구사항]**

1. **`node_add` 이벤트 (데이터 스트림)**:
* 노드가 추가될 때 단순 팝업이 아니라 홀로그램이 스캔되듯 나타납니다. 이때 `image_path`나 `pid` 같은 메타데이터가 UI에 풍부하게 표시되므로, 페이로드에 **더 많은 파일 경로 컨텍스트**가 담겨있으면 시각적으로 훨씬 화려해집니다.


2. **`verdict: "ransomware"` 수신 (글리치 효과)**:
* 위협이 감지되면 화면이 붉게 변하는 대신, UI 패널에 **글리치(지지직거리는 화면 깨짐) 효과**와 함께 마젠타 색상의 홀로그램 경고창이 오버레이됩니다.


3. **`evidence` 배열 데이터의 활용**:
* 상세 패널이 투명한 데이터 스트림처럼 보이도록 디자인됩니다. A와 C가 `evidence` 항목을 단순 텍스트가 아닌 `{"key": "Target", "value": "/home/user/doc"}` 처럼 쪼개서 보내주면(v1.1 스키마 제안 참조), 홀로그램 패널이 훨씬 더 전문가용 장비처럼 렌더링됩니다.

### 3. High-Contrast Retro Terminal (고대비 레트로 터미널) 테마 연동 명세서

**[프론트엔드 렌더링 컨셉]**

* **시각적 목표**: 복잡한 그래픽 배제. 순수 텍스트와 ASCII 기호, 빽빽한 로그로 이루어진 극한의 가독성과 '시스템 해커/엔지니어' 감성.
* **주요 색상**: 퓨어 블랙(#000000) / 터미널 그린(#00ff00) / 앰버 경고(#ffb000) 또는 원색 레드(#ff0000)

**[백엔드(A) 데이터 연동 요구사항]**

1. **`node_add` 이벤트 (원시 로그 출력)**:
* 프로세스 트리가 둥근 노드가 아니라 `+--- [PID: 1234] bash` 같은 **ASCII 텍스트 트리** 형태로 화면에 실시간 프린트됩니다.
* **초당 이벤트(Burst) 처리량 극대화**: 그래픽 렌더링 부하가 거의 없으므로, A가 수백 개의 이벤트를 한 번에 쏟아내도(Burst) 브라우저가 버벅거리지 않고 터미널처럼 빠르게 텍스트를 위로 밀어 올리며 소화할 수 있습니다.


2. **`verdict: "ransomware"` 수신 (Critical Alert)**:
* 복잡한 이펙트 없이 텍스트 줄에 깜빡이는 **`[ CRITICAL ALERT ]`** 태그가 삽입됩니다.


3. **A를 위한 팁**:
* 이 테마는 '정보의 밀도'가 생명입니다. fanotify에서 수집된 로우레벨(Raw) 데이터를 가공하지 않고 날것 그대로(예: flag 값, raw timestamp 등) WS 페이로드에 욱여넣어 주시면, UI가 이를 모두 터미널 로그로 뿌려주어 시스템의 기술적 깊이를 완벽하게 어필할 수 있습니다.
