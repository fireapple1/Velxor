시스템 아키텍처 — 4계층

┌─────────────────────────────────────────────────────┐ │ ① Rust Collector │ │ fanotify / events.jsonl 폴링 (STUB 모드) │ └──────────────────┬──────────────────────────────────┘ │ BehaviorEventV1 (JSONL, schema v1.1) ▼ ┌─────────────────────────────────────────────────────┐ │ ② Rust Aggregator │ │ 1초 sliding window · burst 감지 │ │ FileWrite ≥ 50/s or FileRename ≥ 30/s │ └──────────────────┬──────────────────────────────────┘ REST POST /classify :8765 ─────────────────────▶ ┌─────────────────────────────────────────────────────┐ │ ③ Python 분류 엔진 │ │ Flask + Waitress (threads=4) │ │ LR predict_proba → verdict (lr / rules / fallback) │ └──────────────────┬──────────────────────────────────┘ │ ClassifyResponseV1 ▼ ┌─────────────────────────────────────────────────────┐ │ ④ Electron + React UI │ │ WebSocket :7000 + REST :7001 │ │ 실시간 타임라인 · alert 배너 · Block 버튼 │ └─────────────────────────────────────────────────────┘
4계층 단방향 파이프라인, 각 경계는 schema v1.1로 고정. Rust가 WS :7000과 REST :7001을 동시에 serve합니다. Python engine은 :8765에서 classify 전용으로 동작합니다.

def classify(features: dict) -> ClassifyResponseV1:
    proba = lr_model.predict_proba([feature_vector])[0][1]
    if proba >= 0.5:
        source = "lr"                   # lr-2026w7
    elif rules_engine.matches(features):
        source = "rules"                # rules-v1
    else:
        source = "rules-fallback"       # rules-fallback-v1
    return ClassifyResponseV1(
        label="ransomware" if proba >= 0.5 else "benign",
        confidence=float(proba),
        source=source,
    )

정직성 Disclaimer

  • 합성 PoC 기준 — AC5 수치(TP 30/30, FP 0/10)는 합성 생성 샘플 대상. 실제 랜섬웨어(real-world malware) 미검증. (synthetic PoC, not real-world malware)
  • AC3 영상 STUB=engine 모드 — Rust+fanotify는 실제 동작, Python 분류 엔진만 confidence 0.95 하드코드. 분류 정확도가 아닌 파이프라인(UI·WS·aggregator)을 검증하는 영상.
  • gen-negative 합성 한계 — negative 샘플은 1초 window 정규화 기준으로 생성. 실제 정상 프로세스의 다양한 파일 I/O 패턴을 완전히 커버하지 않음.
  • FAN_RENAME / FAN_REPORT_DFID_NAME v1.1 deferred — rename 이벤트에서 정확한 file_path 추출은 미구현 (Future Work).
