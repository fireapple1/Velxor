한 줄 요약

Windows 커널 레벨에서 악성코드의 행위를 실시간으로 감시하고, Rust 서비스 레이어를 통해 React UI로 전달해 시각화 + AI 판정까지 하는 백신 프로그램. 시그니처 없이도 "지금 이 프로세스가 뭔가 이상한 짓을 하고 있다"는 걸 행위 기반으로 잡아낸다.

전체 구조 (4계층)

① 커널 드라이버 C + WDK
Ring 0
OS 가장 깊은 곳에서 돌아가는 감시자. 파일 접근, 프로세스 생성, 레지스트리 변경을 가장 먼저 감지한다.
미니필터 드라이버로 파일 I/O 가로채기 · 프로세스 생성 콜백 (PsSetCreateProcessNotifyRoutine) · IOCTL로 유저모드에 이벤트 전달
↕ IOCTL
② 유저모드 서비스 (브릿지) Rust
Ring 3
커널과 UI 사이의 중간 다리. 드라이버에서 오는 이벤트를 받아 가공하고, UI로 WebSocket 스트리밍한다.
IOCTL 수신 → 이벤트 파싱 → Python 분석엔진 호출 (REST API) → 판정 결과를 WebSocket으로 UI 전송
↕ REST API
③ 분석 엔진 Python
Rust 서비스에서 요청이 오면 파일을 정적 분석하고 AI 모델로 악성 여부를 판정한다.
pefile로 PE 헤더 파싱 · 해시 → VirusTotal API 조회 · 행위 로그 → XGBoost/Random Forest로 악성코드 분류
↕ WebSocket
④ UI TypeScript + React + Electron
사용자가 보는 화면. 실시간으로 이벤트가 흘러들어오고, 그래프와 타임라인으로 시각화된다.
프로세스 트리 실시간 렌더링 (React Flow / D3) · 위협 타임라인 · AI 판정 결과 + 신뢰도 표시 · 차단/허용 버튼
왜 Electron? 웹 기술(React + TS)로 UI를 만들되, 네이티브 앱처럼 배포 가능. WebSocket으로 Rust 서비스와 통신하면 돼서 구조가 깔끔하다.

악성코드 하나가 탐지되는 흐름

1
의심 파일이 실행됨 → 커널 드라이버가 프로세스 생성 콜백으로 즉시 감지
2
드라이버가 IOCTL로 Rust 서비스에 이벤트 전달 (프로세스명, PID, 파일 경로 등)
3
Rust 서비스가 Python 분석엔진에 REST 요청 → PE 파싱 + 해시 조회 + AI 모델 판정
4
분석 결과가 Rust를 통해 WebSocket으로 UI에 스트리밍
5
UI에서 실시간으로 프로세스 트리 노드 추가, 위협이면 빨간색으로 하이라이트
6
AI가 "랜섬웨어 92% 확률" 판정 → 자동 차단 or 사용자에게 알림
커널 드라이버 → IOCTL → Rust 서비스 → REST → Python 엔진
Rust 서비스 → WebSocket → React UI

개발 순서

1
각자 개별 모듈 먼저 — 드라이버는 이벤트 로그 출력, Python은 파일 분석 API, React는 더미 데이터로 UI 완성
2
IOCTL 인터페이스 합치기 — 드라이버 ↔ Rust 서비스 연결. 이벤트가 실제로 전달되는지 확인
3
전체 파이프라인 연결 — 파일 실행 → 커널 감지 → Rust → Python → UI까지 엔드투엔드로 동작 확인
4
실제 악성코드 샘플로 테스트 — 격리 VM에서 랜섬웨어 샘플 실행, 탐지율 측정 후 모델 튜닝
개발 환경 주의: 커널 드라이버는 반드시 VM에서만 테스트할 것. 잘못 짜면 BSOD (블루스크린) 뜬다. 테스트 서명 모드(bcdedit /set testsigning on)로 로드해야 함.
